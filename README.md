## 👋 About Me

<table align="center">
  <tr>
    <td width="50%" valign="top">

        <b>Université Moulay Ismaïl</b> (Faculté des Sciences de Meknès). My engineering focus centers

## 🌟 Featured Projects

<table align="center">
  <tr>
    <td width="33.3%" valign="top">
      <div align="center">
        <h3>🤖 Agent Readiness Auditor</h3>
        <sub>Autonomous AI &amp; Web Discoverability</sub>
        <br /><br />
        <a href="https://github.com/abdertalibi-gif/Agent_readiness_auditor">
          <img src="https://img.shields.io/badge/View_Repository-00F0FF?style=for-the-badge&logo=github&logoColor=030712" alt="Agent Readiness Auditor" />
        </a>
      </div>
      <br />
      <b>Overview</b><br />
      Production-ready SaaS application that crawls and evaluates websites to assess how ready they are
      to be discovered, understood, and navigated by autonomous AI agents.
      <br /><br />
      <b>Technical Highlights</b>
      <ul>
        <li>SSRF-safe web crawler respecting <code>robots.txt</code> and rate limits.</li>
        <li>60+ deterministic checks across 8 categories (metadata, Schema.org, semantic HTML).</li>
        <li>Weighted 0–100 scoring engine with grounded LLM reasoning and PDF exports.</li>
      </ul>
      <b>Stack:</b> Python, FastAPI, Next.js 15, TypeScript, Celery, Docker
    </td>
    <td width="33.3%" valign="top">
      <div align="center">
        <h3>📱 AttendQR</h3>
        <sub>Academic PFE / Security &amp; Real-Time Systems</sub>
        <br /><br />
        <a href="https://github.com/abdertalibi-gif/Qr_code_pfe-">
          <img src="https://img.shields.io/badge/View_Repository-38BDF8?style=for-the-badge&logo=github&logoColor=030712" alt="AttendQR" />
        </a>
      </div>
      <br />
      <b>Overview</b><br />
      Graduation project (PFE) implementing a secure university presence management platform utilizing
      dynamic cryptographic QR codes and live WebSocket streams.
      <br /><br />
      <b>Technical Highlights</b>
      <ul>
        <li>Dynamic time-based QR code token rotation with anti-replay fraud prevention.</li>
        <li>5-tier Role-Based Access Control (Admin, Professor, Student, Dept Head).</li>
        <li>WebSocket live monitoring (Daphne), ~45 REST endpoints, Flutter client, and UML models.</li>
      </ul>
      <b>Stack:</b> Python, Django, DRF, WebSockets, Flutter (Dart), PostgreSQL, Docker
    </td>
    <td width="33.3%" valign="top">
      <div align="center">
        <h3>🦾 Mobile Robot Simulator</h3>
        <sub>Kinematics Engine &amp; Autonomous Telemetry</sub>
        <br /><br />
        <a href="https://github.com/abdertalibi-gif/robotique">
          <img src="https://img.shields.io/badge/View_Repository-818CF8?style=for-the-badge&logo=github&logoColor=030712" alt="Mobile Robot Simulator" />
        </a>
      </div>
      <br />
      <b>Overview</b><br />
      Scientific two-wheel differential drive simulation engine implementing precise kinematics,
      autonomous collision avoidance, and trajectory telemetry.
      <br /><br />
      <b>Technical Highlights</b>
      <ul>
        <li>Deterministic physics core with &Delta;t = 0.1s time-step and wheel velocity limits.</li>
        <li>Strict separation of physics engine (single source of truth) from React HUD.</li>
        <li>Custom <code>.obs</code>/<code>.pts</code> scenario parsers with JSON and CSV trajectory exporters.</li>
      </ul>
      <b>Stack:</b> TypeScript, React, Vite, Canvas, Kinematic Models
    </td>
  </tr>
